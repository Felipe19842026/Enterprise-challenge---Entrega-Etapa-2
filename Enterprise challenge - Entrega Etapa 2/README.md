# Health Sync Solutions

Site institucional em HTML, CSS e JavaScript para apresentação da plataforma HSS.

## Estrutura

- `index.html`: página inicial
- `solucao.html`: detalhes da solução
- `credenciamento.html`: pré-credenciamento de profissionais
- `contato.html`: solicitação de demonstração institucional
- `style.css`: estilos visuais e responsivos
- `script.js`: navegação mobile, validação dos formulários e geração de protocolo
- `assets/logo-hss.svg`: identidade visual
